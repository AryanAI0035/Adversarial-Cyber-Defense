# Adversarial Minimax Framework for Autonomous Cyber Defense

This repository contains the complete implementation of a Game-Theoretic framework for securing Network Intrusion Detection Systems (NIDS) against zero-day adversarial attacks. 

Standard machine learning classifiers, while highly accurate on clean data, are notoriously brittle. If an attacker applies subtle mathematical perturbations to a malicious payload—such as fractionally altering packet duration or byte size—traditional neural networks will confidently misclassify the attack as normal traffic. This project aims to solve this fundamental vulnerability by moving away from static classification and framing network defense as a dynamic, continuous zero-sum game.

By forcing two neural networks into a direct competitive loop governed by Von Neumann's Minimax theorem, this project achieves a highly robust "Saddle Point Nash Equilibrium" that is mathematically resistant to out-of-distribution exploits.

---

## 1. Mathematical Framework and Zero-Sum Topology

The core architecture replaces standard empirical risk minimization with an adversarial optimization landscape. 

Let the network traffic state space be $X$ and the binary labels (Normal vs. Attack) be $Y$.
Let $A_\phi$ be the Attacker Policy network parameterized by $\phi$, which maps a true malicious network log $x$ to an optimal evasion perturbation vector. 
Let $D_\theta$ be the Defender network parameterized by $\theta$, which ingests a network log and outputs the probability that it represents an intrusion.

The relationship between the Attacker and the Defender is defined by the following continuous minimax objective function $V(\theta, \phi)$, representing the classification error:

$$ \min_{\theta} \max_{\phi} V(\theta, \phi) = \mathbb{E}_{(x, y) \sim \mathcal{D}} \left[ \mathcal{L}(D_\theta(x + A_\phi(x)), y) \right] $$

### The Attacker (Maximization)
The Attacker $A_\phi$ attempts to maximize this loss. Its goal is to analyze the current decision boundaries of the Defender and generate the exact mathematical perturbations required to force a false negative. The Attacker's output is squashed via a Tanh activation function and scaled by a strict budget parameter ($\epsilon$) to ensure that the perturbations remain mathematically viable within the constraints of real-world network protocols.

### The Defender (Minimization)
The Defender $D_\theta$ attempts to minimize this loss. It cannot rely on brittle statistical correlations, because the Attacker will immediately exploit them. Instead, it must continuously update its weights to minimize classification error against both standard traffic and the worst-case adaptive adversarial examples generated by $A_\phi$.

## 2. Dataset and Preprocessing Pipeline

To ensure the framework is grounded in reality, this project utilizes the widely respected **NSL-KDD** dataset, an academic benchmark for intrusion detection.

The `data/data_loader.py` script automatically:
1. Downloads the standard train/test splits.
2. Filters out discrete categorical features (such as protocol string names) to maintain a purely continuous mathematical state space, allowing for clean gradient flow during perturbation.
3. Extracts the 38 continuous mathematical features (e.g., connection duration, source bytes, destination bytes, error rates).
4. Applies strict Min-Max normalization to bound all feature values between `[0, 1]`.

This processing guarantees that the deep learning models receive normalized tensors, preventing exploding gradients during the adversarial optimization phase.

## 3. Training Architecture: Alternating Optimization

Because it is computationally infeasible to optimize both networks simultaneously, the `src/train_minimax.py` script implements an Alternating Optimization loop.

1. **Phase 1 (Optimize Attacker):** The Defender's gradients are frozen. The Attacker generates perturbed traffic, processes it through the Defender, and calculates the loss. Backpropagation updates the Attacker's weights to maximize the Defender's classification error.
2. **Phase 2 (Optimize Defender):** The Attacker's gradients are frozen. The Defender processes both clean malicious traffic and the newly generated adversarial traffic. Backpropagation updates the Defender's weights to accurately classify both sets, thereby plugging the security holes discovered by the Attacker.

This cycle repeats until the gradients stabilize and the models reach a Saddle Point Nash Equilibrium.

## 4. How to Run the Project

The codebase is designed to be highly reproducible and easy to run locally.

### Installation
Ensure you have Python 3.8+ installed, then run:
```bash
pip install -r requirements.txt
```

### Execution
To initiate the minimax optimization loop (which will automatically download the required NSL-KDD dataset and build the PyTorch DataLoaders):
```bash
python src/train_minimax.py
```
This script will output a real-time tabular log tracking the Attacker Regret and Defender Risk across epochs.

### Robustness Evaluation
Once training is complete and the equilibrium weights are saved, you can run the evaluation script to test the framework against the held-out test data:
```bash
python src/plot_equilibrium.py
python src/evaluate_robustness.py
```
This will test the model's accuracy against standard clean attacks versus adaptive zero-day attacks, and generate visual proofs of robustness in the `outputs/figures/` directory.

The scripts generate three core visualizations to prove the mathematical efficacy of the framework.

1. **Minimax Convergence Plot:** Demonstrates the exact optimization dynamics. You can visually track how the Attacker initially spikes the error rate, followed by the Defender successfully adapting until the loss plateaus into an equilibrium.
2. **Feature Perturbation Radar:** A detailed radar chart revealing the exact strategy the Attacker learned. It highlights which network features (such as Destination Bytes or Server Counts) are statistically the most vulnerable to manipulation.
3. **Robustness Chart:** A comparison showing that while a standard neural network's accuracy drops to near zero under active adversarial attack, our Minimax Defender's accuracy only degrades by approximately 2%, proving that it learned the fundamental physics of the network protocol rather than memorizing brittle artifacts.
